# Orbit Dashboard · Developer Preview 3

This macOS source preview adds local background-service visibility and a shared
Git status window, with consistent dashboard typography and distinct navigation icons.

## Changes

- Opt-in Local Services lists launchd definitions and accessible cron jobs, with
  origin, user/system, type and status filters. Mark your own services, save personal
  descriptions and pin favorites to Overview. Viewing services does not alter jobs.
- Project Git status opens one window with Changed files and History tabs. See up
  to ten local commits, branch/upstream and locally known ahead/behind counts.
  Hover previews show changed paths or the latest commit with its timestamp.
- The Git window stays the same size across tabs and remains open during refreshes.
  Mini previews align with the Git column and appear above their triggers when possible.
- Shared typography roles and card components align Favorite services with the
  rest of Overview. Docker uses a cube, Local Services a circled play symbol,
  and Settings an updated gear.
- New contributions follow Conventional Commits; published history is preserved.

## Install or update

Extract the source ZIP and follow README.md or its AI setup prompt. Python 3.10+
is required. Building the native window requires Apple Command Line Tools.
Existing native users can restart Orbit when their existing source checkout is
updated in place; rebuild with `python3 macos/build.py` if the source location changes.
Preserve your existing local data folder, settings and notes when updating.

This remains a source developer preview. The native bundle references its source
folder and Python interpreter. Signed/notarized standalone downloads, a second-Mac
setup rehearsal and minimum-version compatibility checks remain future work.
The ZIP excludes local settings, action keys, notes, databases and Git history.
